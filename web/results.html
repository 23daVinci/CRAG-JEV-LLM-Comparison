Dramatically faster and cheaper, but a real accuracy cost.

One LangGraph workflow, two decision backends. The classification-style calls (is this passage relevant, is the evidence sufficient, should it retry) are answered either by an LLM (Groq) or by Jev, TypeSafe AI's model that returns typed probabilities instead of generated text.

Held-out test

9 of 45 frozen HotpotQA questions, never seen during tuning. Jev's thresholds were tuned on a 27-query train split and confirmed on a 9-query val split. Test was scored once.

Objective labels

Output under test is the selected document set, scored against HotpotQA's own gold supporting facts. No LLM judge, no generation step.

Paired, live runs

Real Groq and Jev API calls, A/B interleaved per query against a frozen document pool hashed before and after each pair.

Small n, stated plainly

Read the speed and cost gaps as large and clear; read the quality gap as real but wide-error-barred until a bigger split confirms it.
