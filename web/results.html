jev-bench A/B benchmark of an agentic retrieval workflow Held-out test set, n = 1,000 (head-to-head n = 19)

0.72 F1 on 1,000 unseen questions, at $0.23 per 1,000 queries. Against an LLM: ~12× faster, ~25× cheaper, and the LLM's small accuracy edge is unproven at n = 19.

One LangGraph workflow, two decision backends. The classification-style calls (is this passage relevant, is the evidence sufficient, should it retry) are answered either by an LLM (Groq) or by Jev, TypeSafe AI's model that returns typed probabilities instead of generated text. Jev ran on all 1,000 test questions; Groq's free tier allows only about 30 queries a day, so the side-by-side comparison covers just 19 of them.

Why it's apples to apples

Same compiled LangGraph graph, same selected-document-set task, two interchangeable decision backends.

Decision node, answered by whichever backend is plugged in. Identical node/edge topology for both is asserted by a test, not by convention.

Injection guard

Planted prompt-injection probes, ground truth exact by construction. Held-out set of 200 probes: 100 matched clean/injected pairs.

Jev flagged every injected probe and no clean one. Groq was not run on this set (token quota), so this is a Jev-only result with no comparison implied.

1,100 questions, three disjoint splits

80 train and 10 val questions were used to tune Jev's thresholds, locked at relevance 0.40 and injection 0.50. The 1,000 test questions are disjoint from both and were never used for tuning; thresholds were not re-tuned. Jev completed all 1,000 with 0 failures.

Objective labels

Output under test is the selected document set, scored against HotpotQA's own gold supporting facts. No LLM judge, no generation step.

Shared retrieval, frozen pool

The retrieve step ranks documents semantically with a local embedding model, identical for both backends. Real Groq and Jev API calls against a frozen document pool, hashed before and after each query.

Small n, stated plainly

The head-to-head is 19 random test queries (20 run, 1 lost to a Groq request timeout), so only the Jev-alone number is tightly measured. It supersedes the 10-query pilot (Groq 0.677 vs. Jev 0.533), which was too small to conclude anything.
